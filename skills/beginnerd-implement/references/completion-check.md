# Phase 5 — Evidence-Based Completion Check

Inspect, for EACH approved task/batch:
- Scope, requirements, acceptance, baseline/dependencies and permission recorded; no unauthorized formal tasks or code.
- Actual diff/files and integration effects within approved scope.
- Relevant unit/integration/contract/E2E/security/negative tests really EXECUTED with expected and observed outcomes; IDs/commands/versions linked.
- Critical findings resolved with verifiable evidence; remediation attempts obey 5M and Owner approvals.
- Integration only if allowed; no false release/deployment implication.
- Remaining risks, deferrals and possible PLANNING-02 controlled replanning tracked.
- Source/project state and consented Hindsight checkpoint updated only if confirmed.

**PASS** only with all applicable acceptance evidence; **PARTIAL** with bounded valid results and open gaps; **BLOCKED** for critical risks/prereqs; **UNVERIFIED** for missing evidence. Completed code ≠ deployed release.

Handoff to Phase 6 must include tagged/known build candidate, change history, test evidence, approval boundaries, risk register and rollback needs, never an automatic authorization to deploy.
