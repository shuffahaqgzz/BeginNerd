# Optional Provider Verification

**When:** The user opted into Graphify, Hindsight or both through beginnerd-setup. Do not load or execute these checks when providers were declined. No provider is required to use basic BeginNerd lifecycle skills.

## Read-only preflight
- Identify the chosen provider(s), actual available adapter/tool methods, version, scope, permissions, and credential source **without disclosing secrets**.
- Inspect current registration and namespace before installation; prevent duplicates and unauthorized global changes.

## Graphify (only if selected)
- Use provider-native safe reads to inspect an approved project relationship and source freshness.
- Verify that unrelated project knowledge cannot be accessed.
- Any test write needs separate consent, disposable data and authorized cleanup.

## Hindsight (only if selected)
- Require explicit informed consent for persistent project memory.
- Retain one harmless test checkpoint in an isolated, authorized namespace and confirm acknowledgement.
- Recall the marker, check its source, scope, time and content, and record a sanitized verification reference.
- If a required write fails, preserve its technical status without claiming memory saved. Do not invent a successful recall.

## Cross-session and consent
Start a fresh session only in the approved project and verify that remembered content agrees with the canonical docs. Test disabling/reconfiguration with the Owner's consent. If not selected, provider status is NOT_ENABLED, not PARTIAL/BLOCKED for the framework.

Never copy secrets or private memory into GitHub issues, source repository evidence or chat logs.
