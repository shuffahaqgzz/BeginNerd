# Phase 3 Planning Readiness Check

Validate actual evidence, not document count. Inspect:
1. Approved MVP and G2 unblocked scope align with roadmap.
2. Outcome milestones, releases, deliverables and acceptance are clear.
3. PLANNING-02 has User-approved Work Structure Agreement, stable task IDs, scope/exclusions and reasonable granularity.
4. Dependencies and cycles checked; blockers and parent links explicit.
5. Risks/resource/time assumptions stated honestly.
6. PLANNING-03 test strategy covers critical function, security and failures.
7. Requirement→design→task→planned test traceability complete for critical features.
8. Canonical docs/decision log consistent with current revisions.
9. Material milestone, hierarchy and test risk decisions user-approved.

**PASS:** usable plan with relevant approvals and no critical blockers. **PARTIAL:** only some tasks unblocked/ready. **BLOCKED:** critical planning conflict, missing approval or dependencies. Annotate unknown evidence UNVERIFIED.

Do not add a formal gate or mark a task ready as executable authorization. Phase 4 must separately verify environment.
