# Phase 4 Foundation Readiness Check

Evidence-backed criteria:
1. Baseline repo identity, source SHA, existing edits and intended scope verified.
2. Minimal scaffold/config consistent with approved Solution/Planning and no duplicate installation.
3. Required runtimes/services/versions/dependencies actually tested, with safe scope and compatibility.
4. Quality tooling/lint/build/test commands reproducible where relevant.
5. Agent/harness instructions and supported skill discovery have fresh-session verification where applicable; no unauthorized provider mutations.
6. Project context/decision traceability accessible; Graphify/Hindsight availability/isolation/retain scope described separately and only claimed verified by real provider calls.
7. Permissions, rollback, secrets and unresolved risks recorded.
8. Approved tasks and their test strategy have a clear handoff.

PASS: all relevant foundation checks have actual evidence, no critical blockers.
PARTIAL: subsets usable but integrations/missing tools not verified.
BLOCKED: a critical permission/security/runtime prerequisite prevents affected execution.
Individual claims without evidence = UNVERIFIED. A successful scaffold cannot make Phase 5 completion PASS.
