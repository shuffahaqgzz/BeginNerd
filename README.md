# BeginNerd

BeginNerd adalah framework **Guided Building** untuk membantu pengguna pemula maupun tim campuran memahami, merancang, membangun, menguji, merilis, dan memelihara aplikasi bersama AI coding agent.

> **Status repository:** bootstrap awal. Arsitektur enam fase, delapan skill target, dan 32 workflow sudah disetujui pada tingkat **desain**; implementasi dan pengujian runtime harus dinilai terpisah berdasarkan evidence.

Repository ini menjadi sumber canonical untuk implementasi skill, dokumentasi keputusan, kontrak governance, dan pengujian BeginNerd.

## Prinsip

- Explain Before Execute dan Contextual Learning.
- Research Before Build; Reuse Before Reinvent.
- Explain → Interview → Approve → Record untuk keputusan material.
- Traceability dari kebutuhan sampai bukti penerimaan.
- No Overclaim, No Overengineering, No Overrules.
- Scoped authorization untuk perubahan; verifikasi sebelum menyatakan selesai.

## Cara bekerja

Perubahan yang belum tervalidasi dipersiapkan pada branch melalui pull request. Jangan menganggap sebuah skill terimplementasi atau sebuah integration test lulus hanya karena struktur file atau spesifikasinya sudah tersedia.

Dokumentasi arsitektur, kontrak companion skills, inventaris workflow, dan test harness ditambahkan secara bertahap melalui PR.

## Koneksi dan privasi

Graphify adalah knowledge provider dan Hindsight adalah memory provider yang dipilih pada baseline desain. Konfigurasinya **bukan** bukti bahwa keduanya telah dipasang atau terhubung. Jangan commit kredensial, data pribadi, atau memory privat ke repository.

## Lisensi

Status lisensi belum diputuskan pemilik proyek; tidak ada lisensi open-source yang boleh diasumsikan hanya karena repository bersifat public.
